# Interactive-Convention-Engagement-Platform
A centralized tool for organizers and exhibitors to manage activities and understand attendees' engagement throughout events. 

## Features
### For Organizers
- Create and manage events (Managing the exhibitors and booths)
- View attendees who check into the event
- An overview of attendee participation and booth engagement

### For Exhibitors
- View booth performance and engagement
- Manage interactive booth activities
- Manage rewards and redemption records
- Generate QR codes for booths and create checkpoints for attendee participation

### For Attendees
- Create and manage accounts which can be used across multiple events or conventions
- View booths attending an event
- View specific ongoing activities
